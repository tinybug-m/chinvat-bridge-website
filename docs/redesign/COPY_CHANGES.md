# Copy changes for owner review

Every wording change the redesign makes to the live site. Facts, prices, the
email address and "UK Based // Working Globally" stay verbatim. UI labels move
to sentence case (British style), which is listed once here rather than per
label.

Status: **Proposed**, nothing here is approved yet.

## Site shell (header, mobile menu, footer)

| Where | Live site | Redesign | Why |
|---|---|---|---|
| Header nav | Services, Approach, Insights, About | Services, Approach, Insights, About, **Pricing** | Pricing was only reachable by URL. |
| Header | (no login link; "Client Sign In" only in the footer) | **Client login** | Returning clients find it without scrolling. |
| Header CTA | (none) | Start a conversation | Keeps the main action one click away. |
| All CTAs | Start a Conversation | Start a conversation | Sentence case. |
| Mobile menu | (links only) | Links plus Pricing, Client login, the email address and "UK Based // Working Globally" | The menu now carries everything the header does. |
| Footer column labels | "Disciplines", "Chinvat Bridge" | Explore, Disciplines, Clients | Groups the links by what people come for. |
| Footer | Client Sign In | Client sign in | Sentence case. |
| Footer tagline | UK Based • Working Globally | UK Based // Working Globally | The live footer used a bullet; the hero has always used "//". |
| Footer copyright | © MMXXVI Chinvat Bridge Ltd. All rights reserved. | © 2026 Chinvat Bridge Ltd. All rights reserved. | Arabic numerals read faster. |
| Footer discipline links | All four link to #services | Each links to its own discipline | Same labels, more precise targets. |
